================================================================================
  소미뷰티 프로젝트 — 다른 PC / Cursor에서 이어서 작업하기
================================================================================

■ 준비 (새 컴퓨터에 한 번만)
  1) Node.js LTS 설치  →  https://nodejs.org/
  2) Cursor 설치  →  https://cursor.com/

■ 이 폴더 복사하는 방법 (택 1)
  【방법 A】통째로 복사 (가장 단순)
      COOT_Ai\소미뷰티 폴더 전체를 USB·외장하드·클라우드로 복사
      → 새 PC에 같은 이름으로 풀기

  【방법 B】용량 줄여서 복사 (권장, node_modules는 다시 받음)
      아래 폴더는 복사에서 빼도 됩니다 (나중에 npm으로 복구).
        - node_modules
        - dist
      나머지 파일·폴더는 모두 복사 (특히 .git, src, public, *.html, package.json 등)

  【방법 C】GitHub 사용 (가장 깔끔, 인터넷 되는 곳)
      새 PC에서:
        git clone https://github.com/imseungjun/somi_beauty.git
        폴더 이름을 원하면 소미뷰티로 바꿔도 됨

■ Cursor에서 연 뒤 (터미널)
  프로젝트 루트(소미뷰티)에서:
    npm ci
    (package-lock이 없으면: npm install)
  로컬 미리보기:
    npm run dev
  빌드:
    npm run build

■ 꼭 같이 있어야 하는 것
  - package.json, package-lock.json
  - vite.config.js, vercel.json(있는 경우)
  - src, public, 루트의 *.html
  - .git  →  푸시/풀·히스토리를 쓰려면 통째로 복사하거나 clone 권장

■ 공개 사이트 (배포된 주소, 코드와 별개)
  - https://imseungjun.github.io/somi_beauty/
